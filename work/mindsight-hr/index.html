Overview

Mindsight builds HR software for recruitment and hiring. I designed and delivered features, refactored legacy services and improved stability across multi-tenant platforms.

The problem

Enterprise customers needed to sign in with their own identity providers, internal systems needed secure service-to-service communication, and some critical processing flows were too heavy.

What I did

I developed authentication and system-communication features — SSO login with external IdPs, OAuth2 for internal communication and event journaling for compliance — and, in a team of two, built a job-board application end to end.

Architecture

Simplified view. The Django platform authenticates users through external IdPs, talks to internal services over OAuth2 and records events in a journal.

  • External IdPs (SSO)
  • React apps
  • Django HR platform
  • Job board
  • Internal services
  • Event journal

Engineering challenges

  1. Adding SSO to a multi-tenant system without breaking existing tenants.
  2. Refactoring critical flows while they served real users.

Outcomes

  • Critical processing flows refactored, reducing memory consumption and execution time by over 50%.
  • Job board delivered end to end with a key role in architecture, data modelling, API design, testing and deployment.
  • SSO, OAuth2 and event journaling supporting compliance.

Lessons

  • In multi-tenant systems, authentication is product work, not plumbing.
