Visão geral

Construído para o meu próprio clã: quem atacou, quanto de destruição, quem perdeu ataques — em guerras normais e de liga.

O problema

O jogo mostra uma guerra de cada vez; os líderes precisam de histórico para decidir quem joga.

O que eu fiz

Uma Lambda com Serverless Framework roda a cada 23 horas, executa workflows diferentes para guerras de liga e guerras normais e armazena os resultados por meio de uma factory de serviço de dados que pode alternar entre DynamoDB e armazenamento local. Tipos de erro customizados tratam casos como guerra em andamento ou manutenção da API.

Arquitetura

Uma Lambda agendada extrai dados da API oficial e grava no DynamoDB; o painel em React lê os resultados agregados.
