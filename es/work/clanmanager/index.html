Resumen

Creado para mi propio clan: quién atacó, cuánta destrucción causó, quién se dejó ataques sin hacer, tanto en guerras normales como de liga.

El problema

El juego muestra las guerras de una en una; los líderes necesitan el historial para decidir quién juega.

Qué hice

Una Lambda con Serverless Framework se ejecuta cada 23 horas, sigue flujos distintos para las guerras de liga y las normales, y guarda los resultados mediante una factory de servicios de datos que puede alternar entre DynamoDB y almacenamiento local. Tipos de error personalizados gestionan casos como una guerra en curso o el mantenimiento de la API.

Arquitectura

Una Lambda programada extrae los datos de la API oficial y los escribe en DynamoDB; el panel en React lee los resultados agregados.

Aprendizajes

  • Serverless + una ejecución programada es la forma más barata posible de mantener un pipeline de datos para una comunidad.
