Resumen

Trama de Expedições es un proyecto personal de videojuego y un experimento para construir algo grande con agentes de IA como colaboradores. Es honesto sobre su estado: el PvE offline, el movimiento y el movimiento en red local funcionan; el combate en red, el PvP y una build móvil validada todavía no existen.

El problema

¿Puede una sola persona, trabajando con agentes de IA, construir los cimientos técnicos de un juego móvil multijugador —networking, balanceo, pipeline de contenido— con un estándar profesional?

Qué hice

Un cliente de Unity se apoya en una librería core compartida de .NET, con un spike de match host autoritativo para el networking y meta-servicios (chat, clanes, economía, amigos) cubiertos por tests. Scripts de Python para Blender generan LODs, retratos e iconos de UI. El estado del proyecto, las decisiones y los traspasos están documentados para los agentes en archivos dedicados.

Arquitectura

Arquitectura de prototipo: el cliente de Unity se comunica con un match host autoritativo; un core compartido de .NET mantiene las reglas idénticas en ambos lados; los bots ejecutan rondas de balanceo automatizadas.

  • Unity client
  • Authoritative match host
  • Shared .NET core
  • Meta services (chat, clans, economy)
  • Bot balancing runs

Retos de ingeniería

  1. Mantener las reglas del juego deterministas entre cliente y host.
  2. Balancear mapas sin una base de jugadores.

Resultados

  • 72 partidas de bots por mapa mantuvieron cada uno de los 6 mapas entre un 35% y un 65% de tasa de victorias.
  • Prueba de estrés con 400 unidades a un frame time p95 de unos 3,3–3,5 ms (headless, Mac).
  • Animación esquelética con LOD para 18 personajes.
  • Más de 500 commits, incluidos más de 190 pull requests desde ramas de agentes de IA.

Aprendizajes

  • Los agentes de IA son productivos cuando el estado y las decisiones del proyecto están por escrito para ellos.
